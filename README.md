Customer churn is one of the major challenges faced by businesses, especially subscription-based companies. Understanding why customers leave can help organizations take proactive actions to improve customer retention and increase revenue.

This project focuses on exploring, analyzing, visualizing, and predicting customer churn using Python and Machine Learning.

The project covers the complete data analysis workflow — from data cleaning and Exploratory Data Analysis (EDA) to correlation analysis, visualization, machine learning model building, and model evaluation.
